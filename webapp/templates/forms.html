Reading this table

Mode is how values land on the page. fillable writes into the PDF's own AcroForm fields; overlay stamps text onto a flat scan by anchor or coordinate, which is the common case for Florida county forms.

Category coverage lists the statutory categories ({{ categories | join(', ') | replace('_', ' ') }}) that form has a checkbox rule for. A client's category is set once in their file; each form then marks its own box. A form showing no category checkbox simply doesn't ask.

Edit opens a mapping with the blank form beside it: click the page to get a coordinate, and preview the filled result against a real client before saving. Every save keeps a backup. Adding a brand-new form still starts with docs/adding-forms.md.
