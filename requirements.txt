# Pinned exactly, on purpose.
#
# The toolkit's promise is that the same client file produces the same PDF. That
# holds for a given set of libraries and not across them: reportlab decides where a
# glyph sits, pypdf decides how pages merge, and a minor release of either can move
# text on a filed government form without anything failing. Every generated PDF
# records the versions that produced it (see the generation log), and these are the
# versions the mappings were verified against.
#
# To move one: bump it here, run `pytest` (the golden test checks real coordinates on
# the real Clerk form), then re-run docs/verification-checklist.md before filing.
